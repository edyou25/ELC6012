# Assessment 3：批判性反思写作要求（中文总结）

来源：[Guidance on Writing the Critical Reflection](../Guidance%20on%20writing%20the%20critical%20reflection.pdf)（共 2 页）  
课程：ELC6012 Thesis Writing for Research Students

## 1. 作业目的

回顾本课程的学习经历，深入、批判性地反思：你对学术写作的认识和写作方法发生了什么变化，获得了哪些知识与技能，以及如何将这些收获应用于自己的学位论文写作。

重点是结合具体例子分析自己的学习与变化，而不只是复述课程内容。

## 2. 核心要求

| 项目 | 要求 |
| --- | --- |
| 聚焦范围 | 从下列论文部分中选择 **一个**：摘要（Abstract）、引言（Introduction）、文献综述（Literature review）、研究方法（Methodology）、结果与讨论（Results and discussion）、结论（Conclusion）。 |
| 参考材料 | 选择 **至少两篇本学科领域的博士学位论文（PhD theses）**。 |
| 分析与举例 | 使用所选博士论文中的 **带批注示例**，支持对学习经历的详细、批判性反思；批注示例可以使用图片。 |
| 比较与解释 | 讨论示例中体现的本学科写作特点与课堂所学有哪些相同或不同，并解释原因。 |
| 篇幅 | 正文 **至少 500 words**，**不包括带批注示例**。原文按 words 计数，不应理解为 500 个中文字。 |
| 提交时间 | **最后一节课结束时间起 48 小时内**提交。具体截止日期需根据实际下课时间计算。 |
| 参考文献 | 文末列出所选博士论文及其他已引用资料，并用括号注明所用引用格式名称，如 APA 或 IEEE。 |

## 3. 反思需要回应的问题

- **对自己的认识：** 通过本课程，你对自己作为学术写作者有了哪些新认识？
- **具体收获：** 你获得了哪些明确的写作知识或技能？
- **变化的证据：** 能否用所选博士论文中的带批注示例，展示你的学习收获与变化？这些示例与你在课堂上学到的内容有何异同？为什么？
- **实际应用：** 你会如何将所学应用于自己的学位论文写作？

## 4. 建议结构

> 原文明确说明：以下结构仅供参考，可按实际需要调整，并非必须照搬的固定模板。

### 4.1 引言（Introduction）

- 简要介绍本次反思的主题与内容。
- 解释为什么选择这些本学科的博士论文作为分析材料。

### 4.2 作为学术写作者的变化（Your changes as an academic writer）

- 总结课程学习让你对自身学术写作有了哪些认识。
- 用具体例子说明自己的变化；如可行，可使用所选博士论文中的带批注示例。

### 4.3 知识、技能与学术规范（Knowledge, skills and academic conventions）

- 聚焦上文列出的一个论文部分。
- 使用所选博士论文中的带批注示例，展示观察与分析，内容可包括：
  - **结构：** 该部分如何组织内容。
  - **衔接与连贯：** 段落内部和段落之间如何建立联系。
  - **学术规范：** 学术风格、语言使用、引用方式等。
  - 其他与所选主题相关的写作问题。
- 比较这些特点与课程所学的异同，并解释原因。

### 4.4 结论（Conclusion）

- 总结最重要的学习收获。
- 说明如何将这些收获应用于自己的学位论文写作。

### 4.5 参考文献（References）

- 列出正文引用的资料，包括所选博士论文。
- 用括号注明引用格式名称，例如：`References (APA)` 或 `References (IEEE)`。
